# Week 11 Linked List Practice Problems

Part A implementations for the linked-list practice sheet:

1. Circular singly linked-list traversal
2. Doubly linked-list tail insertion
3. Removing the first `k` nodes
4. Deleting the n-th node
5. Splitting a list into two halves
6. Reversing the first `k` nodes
7. Counting nodes
8. Checking whether a list is empty
9. Circular singly linked-list end insertion
10. Doubly linked-list last-node deletion

Every source file includes a small `main` demonstration and its time/space complexity.
