# STEP Solutions

Java solutions completed as part of the SRM Talent Empowerment Program (STEP).

## Structure

Solutions are organised by semester and week. Each week contains one Java file for every assigned problem.

```text
Semester 3/
  Week 1/
    Week 1 - Solutions/
  Week 2/
    Week 2 - Solutions/
```

## Week 1

- Duplicate Seat Checker
- Typing Accuracy Checker
- Traffic Signal Streak Analyzer
- Warehouse Inventory Balancer
- Movie Review Word Length Profiler

## Week 2

- ATM PIN Length Validator
- Word Reversal Encoder
- Product Inventory CSV Parser
- Library ISBN Normalizer & Validator
- Stop-Word-Filtered Word Frequency Report
