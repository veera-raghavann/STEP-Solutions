# STEP Solutions

Java solutions completed as part of the SRM Talent Empowerment Program (STEP).

## Structure

Solutions are organised by semester and week. Each week contains separate `class_problems` and `assignment_problems` folders where the corresponding problem sheets are provided.

```text
Semester 3/
  Week 1/
    Week 1 - Solutions/
  Week 2/
    Week 2 - Solutions/
  Week 3/
    Week 3 - OOP/
      class_problems/
      assignment_problems/
  Week 7/
    Week 7 - Abstraction & Interface/
      class_problems/
      assignment_problems/
  Week 8/
    Week 8 - Coding Assignment/
      class_problems/
      assignment_problems/
```
