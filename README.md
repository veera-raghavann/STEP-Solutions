# STEP Solutions

Java solutions completed as part of the SRM Talent Empowerment Program (STEP).

## Structure

Solutions are organised by semester and week. Each week contains one Java file for every assigned problem.

```text
Semester 3/
  Week 1/
    Week 1 - Solutions/
  Week 2/
    Week 2 - Solutions/
  Week 3/
    Week 3 - OOP/
      class_problems/
      assignment_problems/
  Week 4/
    Constructors and Java Keywords/
      class_problems/
      assignment_problems/
  Week 5/
    Access Modifiers and Encapsulation/
      class_problems/
      assignment_problems/
  Week 6/
    Inheritance and Polymorphism/
      class_problems/
      assignment_problems/
```
